01 · 我们处理哪些信息

当前版本无需注册 Fanumi 账号。我们不要求您为使用本地记录功能提供手机号码、身份证号码或登录第三方社交账号。

档案、时间线与物料收藏

信息：您主动填写的名称、生日或纪念日期、标题、文字故事、标签，以及导入的图片、视频、裁剪位置、边框和主题设置。

用途与方式：在设备中保存、检索、展示、编辑和生成您选择的卡片或记录；读取所选媒体的尺寸、类型、时长等信息以正确呈现内容。这些记录与媒体只在设备本地处理，不上传至任何服务器；您主动选中图片进行阿里云抠图的情况见第三节。

提醒、小窝与角色装扮

信息：您设置的提醒日期与内容、角色和房间配置、家具位置、互动进度及星币记录。

用途与方式：在设备上保存偏好与进度，并通过系统本地通知发送您设置的提醒。这些记录不上传至任何服务器，当前版本没有账号云同步。

App 之外的主动邮件联系

信息：发件邮箱、问题描述，以及您自行选择发送的截图或附件。

用途与方式：仅在您主动通过邮箱联系时收到，用于答复咨询、处理反馈及个人信息权利请求；App 不会自动发送这些信息。请避免发送密码、密钥、证件照片及与问题无关的私密内容。

当前版本未接入第三方广告投放或用户行为统计 SDK，不以广告追踪或画像推荐为目的获取您的收藏，也不出售您的个人信息。

02 · 您可以选择的权限

  • 相册读取：用于选择并导入图片、视频。系统提供有限照片访问时，您可以仅授权选中的照片。拒绝后，相应的相册导入功能不可用，已保存内容仍可查看。
  • 向相册添加照片：用于将您主动保存的图片或卡片写入系统相册。拒绝后无法通过该方式保存，不影响 App 内编辑。
  • 通知：用于生日、纪念日或您设置的事项提醒。关闭后不再通过系统通知提醒，仍可在 App 中查看相关记录。

您可在 iPhone“设置”中找到 Fanumi 或相应权限类别进行管理，具体位置随 iOS 版本可能不同。当前功能不申请通讯录、定位、麦克风、相机或跨 App 广告追踪权限。

撤回相册权限不会自动删除此前已由您导入 App 的副本；删除方式见第六节。

03 · 云端抠图与人像效果

云端抠图是一项可选联网功能。首次使用时，App 会提示并由您选择是否继续。之后仅在您主动对选中图片执行抠图时处理，不会在后台扫描并上传整套图库。

需要联网处理时，App 会将您选定、可能已裁剪并为处理而压缩的图片上传至我们使用的阿里云对象存储，再调用阿里云人体分割服务。服务识别图像中的人体轮廓，将主体与背景分离，并将透明背景结果返回设备。云端请求同时涉及传输所必需的 IP 地址、请求时间和请求标识等技术信息。

本功能用于图像编辑，不用于核验人物身份、人脸比对或建立人脸身份库。我们不会将您提交的图片用于训练我们的模型、广告投放或对外公开展示。图片可能包含您或他人的肖像与其他个人信息，请仅提交您有权处理的内容，避免上传证件、私密场景等不必要的敏感内容。

轮廓描边、光效及浮雕展示使用设备端的图像处理与渲染；这些效果在设备本地完成，不会将图片或效果数据上传至服务器。浮雕外观属于视觉效果，不是人物真实三维身体或身份信息的测量结果。

抠图结果及必要缓存保存在设备上。云端原图的删除流程与异常情况见第五节。拒绝云端抠图不影响本地档案、时间线和物料收藏等基础功能。

04 · 第三方服务与信息提供

阿里云对象存储与视觉智能开放平台

提供方：阿里云计算有限公司。

使用场景：您主动使用云端抠图时，通过网络接口暂存图片并执行人体分割。

涉及信息：选定图片、分割结果，以及请求传输和服务安全所需的 IP 地址、请求时间、请求标识等技术信息。

处理区域：当前抠图使用中国内地上海地域的服务。

官方说明：阿里云隐私政策及用户业务数据说明。

相册选择、保存、通知和系统分享由 Apple 系统能力提供。您主动把内容分享至其他应用后，接收方按照其自身规则处理收到的内容；您可以在发送前取消分享。

我们使用的 SnapKit、IGListKit 等界面组件用于本地布局和列表显示，不因这些组件将您的图片或档案传给其开发者。

我们仅在实现已说明的功能、取得必要授权或履行法定义务时处理和提供相应信息。委托服务商处理时，我们依法明确处理目的、范围及保护要求。发生合并等导致信息处理主体变化的，我们会依法告知接收方；改变处理目的或方式时，依法重新取得同意。

05 · 保存地点、期限与安全

设备上的记录

除主动提交的抠图图片外，档案、时间线、媒体副本和房间配置等用户内容仅保存在您的设备内，持续保存以便您使用，您可按第六节管理。当前版本未启用应用内 iCloud 同步；您自行开启的系统整机备份、设备迁移或外部导出由相应系统及服务规则管理。

为减少重复处理，设备可能保存缩略图、抠图结果及浮雕等派生缓存。缓存清理与您主动保存的原图或编辑结果不同；删除应用可移除其应用容器内的数据，系统备份和已导出的副本需另行管理。

抠图临时文件

上传至我们所用阿里云存储空间的图片采用私有访问，仅为完成本次抠图生成临时访问凭据。处理成功或请求失败后，App 会发起删除原图的请求。

删除请求可能受断网、应用中断或云服务异常影响而未完成，临时访问链接失效也不等于文件已删除。如果您希望核实或处理临时图片的删除，可通过本政策邮箱联系我们，并提供大致处理时间及问题描述；无需先重新发送原图。

返回图片由 App 下载用于本地编辑。阿里云服务自身的技术日志和结果处理遵循其适用协议及隐私规则；您可通过我们联系处理相关个人信息请求。

反馈信息与保护措施

您通过邮件提供的信息仅在处理反馈、解决相关争议和履行法定义务所必要的期间保存，目的完成且无法定保留要求后删除或匿名化。我们不会仅因收到咨询邮件而将您加入营销名单。

我们采用加密网络传输、私有文件访问等措施保护信息。若发生个人信息安全事件，我们将依法采取补救措施，并根据事件影响履行通知、报告等义务。请同时妥善保管设备并及时安装系统与应用更新。

06 · 查阅、删除与撤回同意

  • 查阅、更正、复制：在对应档案、时间线、图库或物料页面查看和编辑内容；可使用现有保存、分享功能复制支持导出的媒体。其他请求可通过邮箱提出。
  • 删除单项资料：在相应记录的编辑或删除入口操作。
  • 清空档案资料：通过设置中的“清空本地资料”删除档案、时间线及相关媒体并移除对应提醒。房间偏好及部分本地缓存可能另行保存；如需移除应用容器内全部数据，请使用 iOS 的“删除 App”，而非保留数据的“卸载 App”。
  • 管理副本：上述操作不会删除您系统相册中的原始照片、已分享给他人的内容或系统备份，请在相应位置单独管理。
  • 撤回授权：可在系统设置中关闭相册或通知权限；不再发起云端抠图即可停止后续图片上传。需要撤回其他同意或请求删除已处理信息时，请联系我们。
  • 停止使用：当前版本无需 Fanumi 账号，因此没有独立的账号注销步骤；您可以删除数据并停止使用或删除 App。

撤回同意不影响撤回前依法进行的处理。对于请求，我们只会在必要范围内核实身份与相关事实，不会以提供与请求无关的信息为条件。我们会及时答复；如依法不能满足请求，将说明理由及可行的后续途径。您也可依法向个人信息保护相关部门投诉。

07 · 未成年人使用与本地资料

本地保存的规则同样适用于未成年人。除用户主动提交图片使用阿里云抠图外，App 不会将未成年人的档案、照片、文字、生日或使用记录上传至任何服务器，也不会建立未成年人的服务器端资料库。开发者无法远程查阅、修改或代为删除这些本地记录。监护人可指导未成年人在设备上查看、编辑或删除资料，具体操作见第六节。

未成年人应在监护人指导下阅读本政策并使用相应功能。云端抠图会上传用户选中的图片；涉及不满十四周岁未成年人的个人信息时，应事先取得其父母或其他监护人依法要求的同意。请不要在缺少必要授权时将此类图片提交云端处理。拒绝抠图不影响本地收藏等基础功能。

如果监护人认为某张图片在未取得必要同意的情况下被提交至阿里云，可通过联系邮箱提出核实、停止处理或删除请求。此处请求仅针对已经提交的云端图片及您主动提供的联系信息，不意味着开发者持有或可以访问设备内的其他资料。

08 · 网页访问与相关技术

本说明页面不要求登录，也不提供上传图片或填写个人资料的表单。页面自身不设置广告追踪脚本或行为分析 Cookie。

本协议说明页面由 GitHub Pages 托管。GitHub 会为安全目的记录并保存访问者的 IP 地址，无论访问者是否登录 GitHub。网页访问所需的技术信息可能在中国内地以外处理；这与 App 云端抠图使用的阿里云上海服务不同。相关处理规则、联系与权利渠道见 GitHub 隐私声明及 GitHub Pages 数据收集说明。我们不通过本页面接收您的 App 收藏、提供联网图片处理或建立用户档案。

访问网页需要向实际提供网页的服务器传输 IP 地址、浏览器请求信息、访问路径和时间等技术信息，以完成页面传输及必要的安全维护。网页的访问不代表将您的 App 收藏上传到网页服务器。点击外部链接或使用邮件联系时，相应网站或邮箱服务按照其规则处理相关信息。

09 · 本政策的变更

我们会根据实际功能和适用规则更新本政策，并标明日期。涉及处理目的、方式、信息种类或您权利的重大变化时，会通过 App 内提示等适当方式说明；依法需要重新同意的，将在取得同意后实施，不以仅发布新文本替代必要的授权。
